# useCountUp

<SingleLineCodeBlock text={`import { useCountUp } from 'chaya-ui';`} />

A hook that animates a number counting up from a minimum to a maximum value over a given duration. Supports both number and currency formatting.

## Usage

```tsx
const formattedValue = useCountUp(0, 1000, 2000, 'number');
```
