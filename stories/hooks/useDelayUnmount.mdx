# useDelayUnmount

<SingleLineCodeBlock text={`import { useDelayUnmount } from 'chaya-ui';`} />

A hook that delays unmounting a component, giving time for exit animations to complete before the element is removed from the DOM.

## Usage

```tsx
const shouldRender = useDelayUnmount(isMounted, 500);
```
