# Hooks

Custom React hooks provided by chaya-ui for common UI patterns.

## Available Hooks

- [useClipboard](?path=/docs/hooks-useclipboard--docs) — Copy text to clipboard
- [useCountDown](?path=/docs/hooks-usecountdown--docs) — Countdown timer to a target date
- [useCounter](?path=/docs/hooks-usecounter--docs) — Counter with start, stop, and reset controls
- [useCountUp](?path=/docs/hooks-usecountup--docs) — Animated number count up
- [useCurrencyFormatter](?path=/docs/hooks-usecurrencyformatter--docs) — Format numbers as currency
- [useNumberFormatter](?path=/docs/hooks-usenumberformatter--docs) — Format numbers with locale support
- [useDelayUnmount](?path=/docs/hooks-usedelayunmount--docs) — Delay unmount for exit animations
- [useInterval](?path=/docs/hooks-useinterval--docs) — Declarative setInterval
