# useClipboard

<SingleLineCodeBlock text={`import { useClipboard } from 'chaya-ui';`} />

A hook for copying text to the clipboard. Returns the last copied value, a copy function, and a function to check if the clipboard API is supported.

## Usage

```tsx
const [copiedText, copy, isSupported] = useClipboard();
```
