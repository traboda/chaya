# useCounter

<SingleLineCodeBlock text={`import { useCounter } from 'chaya-ui';`} />

A hook that provides a counter with start, stop, and reset controls. Can increment or decrement at a configurable interval.

## Usage

```tsx
const [count, { start, stop, reset }] = useCounter({
  initialValue: 0,
  interval: 1000,
  isIncrement: true,
});
```
