# useNumberFormatter

<SingleLineCodeBlock text={`import { useNumberFormatter } from 'chaya-ui';`} />

A hook that returns a function to format numbers using `Intl.NumberFormat` with the user's locale. Supports compact notation for large numbers.

## Usage

```tsx
const format = useNumberFormatter();
format(1234); // "1,234"

const formatCompact = useNumberFormatter(10000);
formatCompact(50000); // "50K"
```
