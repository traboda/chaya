# useInterval

<SingleLineCodeBlock text={`import { useInterval } from 'chaya-ui';`} />

A hook that runs a callback at a configurable interval. Pass `null` as the delay to pause the interval. Handles cleanup and callback updates automatically.

## Usage

```tsx
useInterval(() => {
  // runs every second
}, 1000);

// pass null to stop
useInterval(callback, isRunning ? 1000 : null);
```
