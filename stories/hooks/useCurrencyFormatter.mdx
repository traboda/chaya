# useCurrencyFormatter

<SingleLineCodeBlock text={`import { useCurrencyFormatter } from 'chaya-ui';`} />

A hook that returns a function to format numbers as currency strings using `Intl.NumberFormat`. Supports multiple currencies with automatic locale detection.

## Usage

```tsx
const format = useCurrencyFormatter();
format(1234, 'USD'); // "$1,234"
format(5000, 'INR', 2); // "₹5,000.00"
```
