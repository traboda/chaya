# useCountDown

<SingleLineCodeBlock text={`import { useCountDown } from 'chaya-ui';`} />

A hook that counts down to a target date, updating at a configurable interval.

## Usage

```tsx
const [countdown, { setDate }] = useCountDown({ date: targetDate });
```
